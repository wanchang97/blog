    心理

    不是慢慢自我批评而是应学会自我评价

    我好像不太敢于面对自己的所作所为。敢做没错，但似乎不敢当。 一、不敢看的习惯 比如说合影，虽然我很爱美，很希望有好看的照片，我可能会配合拍摄，但是可能和很多人争抢去看合影之间，我看都不喜欢合影里面的自己。 同样看都不敢看的还有后视镜。我在国内学驾照时老师总是说看后视镜、回身看等等，我完全将它视为命令，照着假装看后视镜，但是完全不认真地看——我怕我真的看了里面有一辆车在逼近我，会不知道该怎么办。我会觉得与其让自己失望，不如就让它是一个都为未决的谜（就像那个假装看一眼后视镜）。又或者说，大多情况下我在合影里都不会好看，我很自卑，感觉自己无法承担后果，不如假装不在意。 所以我很怕去审视自己的照片，审视自己的文字，审视自己的语言，审视自己的决定，审视自己的视频，审视或者暴露自己的过去。 二、从来不给自己估分 从小到大所有的考试（包括高考）结束后，我从来没有给自己估分。不是不在意，而是我太在意，同时又很悲观——觉得即便自己估分结束，还有可能有更差的分数（比如说阅卷心情不好），不如直接知道最后的分数，给自己一个痛快。所以我也从来不会想过对成绩或者结果复议，大多是逆来顺受、听天命的心态。像是王小波《黄金时代》里写的被锁住的牛，只知道吃草干活，别的什么都不知道，连杀都不用捆。 三、丧失自我评估的训练 过去我可能因为这种"看似只向前"的忍耐习惯被老师表扬，或者有时候考后刻意强制清除记忆，但偶尔因为发挥好而获得惊喜。但是我觉得这其实丧失了一个自我评估的训练和主体性的掌控。 我习惯于让外界、不知道哪个评价人来评价我过去是优秀还是不优秀、值得还是不值得，但是从来不重视自己的声音和感受。 我对自己过去的表现何以评价？有哪个准备的过程让我自己觉得特别惊叹？有哪一瞬间感觉自己的神经突然很充分很打通？我享受过这个过程吗？我在这次考试或者各种展览里，有没有获得某些如果从未学过就不会有的体验？哪些是真实的客观限制，不是我个人所能掌握的？哪些是我自己知道的、我很有创造性、很坚韧的地方？ 四、外部评价的幻觉 但是真实生活里，后面的无论是 project 还是各种设计展示、包括你的生活安排、你的个人选择之类的，其实都不会有一个真正客观的评价。此时，这个习惯于寻求外面的一个认可或者分数就变得很可笑。因为那不过是另一个人的主观判断而已，还是一个完全不了解你的人。有点像把头放到断头台上，让来往的路人凭心情砍下去。
